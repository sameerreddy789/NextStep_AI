# NextStep AI User Journey Map

## Persona: The Anxious Fresher (Aarav)
**Goal**: Land first SDE job.
**Pain Point**: High anxiety during interviews, doesn't know where he stands.

| Phase | Step | Action | Emotional State | Friction Point | Opportunity |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Awareness** | Landing Page | Reads hero: "Your Path to Career Success" | Hopeful | None | Clear value prop. |
| **Assessment** | Resume Upload | Uploads PDF resume. | Nervous | "Will it read my projects correctly?" | Show real-time extraction progress. |
| **Validation** | Resume Results | Sees 72% ATS score and missing skills. | Worried | "Am I that far behind?" | Provide immediate positive reinforcement. |
| **Challenge** | Start Interview | Clicks "Start AI Interview" CTA. | High Anxiety | **Friction**: Sudden jump from static results to live webcam feed. | Add a "Warm-up" or "Prep Mode" before the actual interview. |
| **Experience** | In-Interview | Answers technical & behavioral questions. | Stressed | Code editor vs. Speech switching cognitive load. | Standardized UI (done in refactor) helps. |
| **Growth** | Results / Feedback| Sees score and AI feedback. | Relieved | "Okay, I'm not that bad." | Detailed "Why" for the score (Explainability). |
| **Action** | Roadmap | Reviews 6-week plan. | Overwhelmed | **Friction**: "6 weeks is too long." | Highlight "First 3 Tasks" or "Quick Wins". |

## Key Insights from Journey Mapping:
1. **The "Cliff"**: The transition from reading results to a live interview is too abrupt. Users need a transition phase.
2. **The "Roadmap Wall"**: 6 weeks can feel like a long time for a fresher looking for an immediate job.
3. **The "Validation Loop"**: Users want to see their score increase *immediately* after completing a task.
